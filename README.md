SmartCloset

Project Overview

SmartCloset is a web-based smart wardrobe application designed to help users organize their clothing items and create suitable outfit combinations. The application provides a digital wardrobe environment where users can manage their clothes and receive outfit suggestions based on available clothing items and weather conditions.

The main purpose of SmartCloset is to simplify outfit selection and provide a more organized and personalized wardrobe management experience.

Features

- Digital wardrobe management
- Clothing item organization
- AI-based outfit generation
- Weather-based outfit recommendations
- Temperature-based clothing suggestions
- Outerwear recommendations based on weather conditions
- Favorite outfit management
- Generate new outfit combinations
- User authentication interface
- Dark mode
- Responsive user interface
- Local storage for maintaining user preferences and application data

Technologies Used

- React.js
- Vite
- JavaScript
- HTML5
- CSS3
- Lucide React
- Browser Local Storage

Installation and Setup

To run the project locally, ensure that Node.js and Git are installed on your computer.

1. Clone the Repository

git clone YOUR_REPOSITORY_URL

2. Navigate to the Project Directory

cd smartcloset

3. Install Dependencies

npm install

4. Start the Development Server

npm run dev

The terminal will provide a local development URL. Open the provided URL in a web browser to access the application.

Production Build

To create a production-ready build of the application, run:

npm run build

The generated production files will be available in the "dist" directory.

Project Structure

The project follows a component-based React structure. The main application files and reusable components are organized within the "src" directory.
